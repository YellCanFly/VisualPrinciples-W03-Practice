## 已修复的重要边界

- 空画布0/4、单文本仅对比可评；缺失维度不按0或100补齐。
- 完全重合副本折叠，全部文字叠放不获得虚假对齐支持。
- 文字跨不同底色保留最差对比，底板和上层遮挡分别处理。
- JSON拒绝不支持的透明度/旋转、未知字段、超限内容和非法颜色。
- 多选数值/微移保持相对位置，线条端点不污染闭合图形数据。
- 保存失败时阻止新建/导入/打开另一作品，当前内存画面仍保留并可导出JSON。
- 切换作品清理已选比较版本，忽略前一作品迟到的快照读取结果。

## 剩余工作与验收边界

1. **性能和字体体积**：四份完整OTF合计约38.7MiB。需在保留中文覆盖与OFL许可的前提下评估WOFF2/按语言分片；测量真实网络首屏、40对象持续拖动、复杂文字布局、评分300ms及PNG2秒目标。当前没有宣称达标。
2. **完整交互验收**：中文输入法真实组合输入、触控拖动/平移、pointer cancel、50/100/150%不同缩放下精确移动、多标签并发、存储配额满需要进一步人工与设备验证。已有文字输入测试不能替代真实IME验收。
3. **与方案的细节差异**：圆固定等比；其他闭合图形尚无等比开关。颜色选择器连续输入的历史粒度尚未专项校验。版本持久化最多100份，当前没有版本删除入口。报告定位目前高亮相关选框，尚未为每条建议绘制专用测量线。
4. **可访问性**：已提供键盘、数值移动、HEX及文字按钮；尚未完成工具UI文字对比、焦点陷阱、目标尺寸和屏幕阅读器的系统审计。紧凑面板字号应结合课堂投屏继续调整。
5. **评分校准**：已有确定性和边界回归；还需结合师生作品检查刻意不规则排布、密集文字、曲线边界的误判。采样及文字行矩形近似见开发记忆。
6. **部署结果**：本项目作为独立Git仓库，remote为 `https://github.com/YellCanFly/VisualPrinciples-W03-Practice.git`，Pages由 `.github/workflows/pages.yml` 自动部署。线上地址为 `https://yellcanfly.github.io/VisualPrinciples-W03-Practice/`，最新发布状态见仓库Actions；设备、性能及可访问性边界仍按以上条目跟进。
