## 数据与编辑细节

`SceneDocument.schemaVersion=2`；`elements`数组顺序就是绘制z顺序，没有独立z字段。背景不占对象/图层。线条端点 `x/y`、`x2/y2` 保存世界坐标，移动时同步平移两个端点；其他形状不得附加端点字段。

历史保存场景深拷贝，最多100步。拖动使用临时draft，requestAnimationFrame预览，松开一次commit；cancel/blur丢弃draft。视图缩放、网格、选框不进入SceneDocument和评分。屏幕坐标通过 `getScreenCTM().inverse()` 转回逻辑坐标。

文字通过HTML textarea编辑，SVG text/tspan展示；文字宽度变化重新换行，高度由measureText推导。空文本退出时删除，一次撤销恢复。输入和导入共享1000/10000字符限制；目前字符串长度按JS length计数。

多选位置必须按首对象变化量平移每个对象，不能将同一个绝对x/y写给所有对象。样式patch按对象类型过滤；只有line/arrow允许x2/y2。锁定对象不移动，但可选、解锁、删除，且仍评分。

## 保存与版本的关键防线

数据库、BroadcastChannel命名空间 `w03-design-lab-v2`；偏好颜色键后缀 `-colors`。IndexedDB stores：documents/backups/snapshots/meta。当前文档从最近成功写入的ID恢复，损坏时读上一份备份。

App保存调用通过Promise队列串行化，约800ms自动保存；persist返回成功boolean。新建/导入/打开其他文档之前保存当前作品；保存失败或冲突时保留当前内存画面并提供JSON导出，不允许直接丢弃后切换。

同revision不同内容或旧revision写入触发StorageConflictError。另一标签页修改时暂停保存，可将当前画面恢复为新副本；该路径尚需真实多标签人工验收。

快照是scene/report深拷贝；普通分析最多10次，存储总上限100。切换documentId必须清compareIds并关闭版本弹窗；异步loadSnapshots结果需取消标记，避免迟到结果写入新作品。上述两个边界已有回归测试。

## 评分的可复算边界

`rubricVersion=2.0`；`fontManifestVersion=local-lab-fonts-1`；layoutVersion包括 `area-2px-line-regions-1` 与 `/canvas-fonts` 或 `/node-fallback`。

浏览器正式评分等待本地字体，使用真实Canvas字宽与换行；Node单元测试无DOM时使用确定性的字宽近似，两者显式区分布局版本，不能将Node分数当作浏览器字体布局的逐分黄金值。

区域颜色、裁切、遮挡、底板包含通常以2逻辑单位采样，大对象自适应约24000格；圆/曲线距离以采样轮廓近似。文字按实际行矩形近似，字腔、行内空格及抗锯齿不逐字形逐像素处理，细小边界可能有误差。这些局限在源码和报告中明确说明。

底板参与实际背景及遮挡，不作为前景结构；无填充框不因包围盒被当作底板。相同外观完全重叠副本折叠为一个视觉单位，保留原ID。MST只对稳定多组评价亲密性；样式使用OKLab；对齐允许多轴、基线/端点且要求另一方向分离。

## 导入、字体与导出

JSON envelope包含format/schemaVersion/scene及可选report。导入校验后重新生成作品与元素ID，忽略旧report。限制：2MiB、40对象、单文本1000字符、总10000字符、字体sans/serif及字重400/700、不透明HEX/none；未知字段、透明度、旋转和外链资源拒绝。

本地字体是 Noto SC（思源体系），四份OTF合计约38.7MiB；字体许可位于public/licenses。prepare_fonts.py从notofonts/noto-cjk官方仓库下载，fontTools生成coverage.json。两种字体常规/粗体均是真实字重，禁止用静默缺字符方框完成正式PNG。

PNG用离屏Canvas按相同shapePath/fontString/measureText重绘，默认2倍；无需将40MB字体嵌入SVG。HTML报告将PNG内嵌为dataURL、自含结果、转义用户文字，使用修订号与场景指纹匹配。导出覆盖层不参与renderSceneCanvas，辅助线不进入文件。

## 部署与后续优先项

Vite `base='./'`，CSS字体URL已在构建中转换为相对路径。静态托管必须用HTTP，hash路由不依赖后端。发布地址为 `https://yellcanfly.github.io/VisualPrinciples-W03-Practice/`，画布链接在其后追加 `#/practice`。

实际工作流为 `.github/workflows/pages.yml`，在 `main` 推送或手动触发时检查、构建并发布 `dist/`，Pages使用GitHub Actions发布源。CI运行65项单元测试及10项Chromium浏览器测试。后续修改在本目录提交并推送即可自动部署，部署结果以GitHub Actions和线上检查为准。
