# 设计四原则实践网站文档

本目录保存设计四原则网站的方案、开发进度与接续记忆。网站包含四原则效果对比和无主题自由画布：用户可以输入文字，添加基础图形，修改元素样式及背景颜色，自由拖动、增删和排布元素，再查看四维评分与百分制综合得分。2026-10-14 已实现首版并接入独立仓库的 GitHub Pages 自动部署，发布地址见项目根 README，最新部署结果见仓库 Actions。

| 文档 | 用途 |
| --- | --- |
| [开发方案](./开发方案.md) | 页面与交互、自由画布、技术架构、部署和功能验收 |
| [评分规则](./评分规则.md) | 四维评分、计算口径、异常处理、反馈和校准方法 |
| [参考资料与设计依据](./参考资料与设计依据.md) | 课件与书籍页码、原则与页面功能的对应关系、官方技术资料 |
| [开发进度](./开发进度.md) | 当前实现范围、验收记录、限制与下一步 |
| [开发记忆](./开发记忆.md) | 运行入口、架构约定、关键问题和接续注意事项 |

继续开发时先读开发进度与开发记忆，再对照开发方案和评分规则。应用源码、测试、静态资源及构建配置均位于 `Footages/W03/W03-Practice/`，本地运行见项目根 README。若使用课程总仓库部署，GitHub Actions 的入口工作流需位于该仓库根目录，具体见开发方案。

自动评分仅依据视觉几何与样式中可观测的关系，不理解文字语义，也不要求预设主题、必需文案或固定元素清单。评分阈值由本项目制定，需通过代表性画面校准。
