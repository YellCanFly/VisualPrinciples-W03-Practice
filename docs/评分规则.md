# 设计四原则实践评分规则

版本：2.0（`rubricVersion: "2.0"`）。适用于自由文字、基础图形和背景颜色组成的无主题画布。按 960×640 逻辑坐标计算，浏览器本地执行，不依赖 AI 或后台。

## 1. 定位与输入

四项分数及百分制综合分是视觉结构参考，不代表客观审美质量。系统可以测量位置、样式、颜色和几何关系，不能理解文字含义、信息归属或作者意图。

输入只有当前场景、实际排版测量和公开的规则配置。无需选择任务、声明标题／正文角色、指定语义分组或选择布局骨架。自动推断只用于反馈，不改动场景，不限制创作。

任何文字与图形都可添加、改写或删除；每次评估依据当前画面，不校验原始文案，不设必需对象或删除惩罚。删除可能减少评价依据，因此分数必须与覆盖范围同时显示。

除明确引用的文字明暗对比方法外，下列阈值和权重均为项目启发式初值，不是参考书给出的通用评分公式。

## 2. 测量、对象与覆盖度

界面缩放和设备像素比不影响逻辑坐标。等待字体加载并换行完成后，测量文字实际行边界与基线；空文本框、选框和参考线不参与评分。矩形、圆角矩形、圆、椭圆、三角形、菱形、五角星按实际区域测量，直线与箭头按实际描边测量。支持线条端点改变方向；不支持的自由旋转属性不得在导入时静默忽略。

空字符串、无填充且无描边、完全出界或完全被遮住的对象不参与结构关系，在报告中列为“未参与：不可见”。与实际背景完全同色且没有可见轮廓的对象同样处理。只剩这些对象时显示“当前没有可评的可见内容”，分数为 N/A。背景色不计为独立对象。首版只支持不透明纯色及无填充，不支持透明度属性；导入时提示不兼容，不静默合成透明场景。

位于下层、真实填充区域完整包含至少两个其他对象的图形，可推断为底板候选：参与实际背景及遮挡计算，不参与前景分组、重复和对齐。无填充的框不能仅凭包围盒被当作背景；细线和箭头不参与几何分组，但可参与重复、对齐、对比。底板推断必须可在报告中查看，无法确定时标注局限，不要求用户补填角色。

完全重合且外观相同的复制对象，在结构分析中折叠为一个视觉单位，保留全部原始 ID。图形之间的有意叠加不一律算错；不能用统一包围矩形代替星形、圆形或线条的真实占据区域计算遮挡。

每项报告同时提供：

- 状态：`valid` 可评、`limited` 证据有限、`not-applicable` 无可靠依据。
- 对象覆盖度：实际参与的不同前景视觉单位数／全部可见前景视觉单位数，附未覆盖原因。
- 子项覆盖：例如“已评可见度；未评视觉差异”，不将缺失子项补成满分。
- 证据：采用的分组、轴线、样式关系和测量值，支持点选定位。

## 3. 亲密性：可见分组是否清楚

至少需要三个可分组对象，并识别出稳定的多个几何组，其中至少一组含两个对象。单组、均匀排列、只有孤立对象或推断不稳定时为 N/A，说明“未发现可比较的组内与组间关系”。这不代表布局失败。

计算对象边缘最短非负间距 `gap`。尺度 `u` 取可分组对象短边的中位数，下限为 16 逻辑单位。使用 `gap/u` 建立最小生成树，在排序边长中寻找最大显著跳变：较长边至少为较短边的 1.8 倍，且差值至少 0.5；计算比值时分母下限 0.05。以两边长的中点切分，切分阈值上下浮动 10% 后分组仍不变才采用。

| 子项 | 计算方式 | 权重 |
| --- | --- | --- |
| 组内紧凑 | 每组内部树边长均值／u；≤0.5 得 1，≥2 得 0，中间线性插值 | 40% |
| 组间区分 | 每组到其他组的最短间距 b，组内树边长均值 a；`clip((b-a)/max(b,0.1u))` | 60% |

`clip(x)=min(1,max(0,x))`。非单例组等权求均值，单例只作为外部邻居；未覆盖的孤立对象会令状态为 `limited`。与其他文字发生明显字形区域碰撞的组内关系，紧凑子项为 0，不能因重叠距离为零获得奖励。

`P=100×(0.4×紧凑度+0.6×区分度)`。此项只能说明形成了几组可见聚合，不能提示“某段文字归属错误”。均匀网格可能没有亲密性分，但仍可获得重复和对齐证据。

## 4. 重复：是否形成稳定的视觉规则

至少需要三个前景视觉单位，且至少两个属于同一元素类型。按文字与各基础图形类型形成比较族；某类型只有一个对象时不参与。全部类型各异时为 N/A，不直接判定混乱。

**样式支持 T**：对同类型族中每个对象，取它与其他对象的最大样式相似度；先求族内均值，再对类型族等权平均。文字比较字号 25%、字体 20%、字重 20%、颜色 25%、内部对齐 10%；闭合图形比较填充 35%、描边 25%、宽高比例 20%、尺寸 20%；线条比较颜色 40%、描边粗细 30%、长度 30%。属性不适用时移除并归一权重。

连续属性相似度从 1 线性下降到 0：字号／尺寸相对差的两端为 5% 与 30%，相对差定义为差值绝对值／较大值；颜色使用 OKLab 欧氏距离，两端为 0.02 与 0.15。字体与内部对齐相同为 1，否则为 0；字重差≤50 为 1、≥300 为 0。描边属性分别计算颜色和粗细后取均值；同为无填充／无描边得 1，仅一方无填充／无描边得 0，不能当作不适用而跳过差异。

**空间节奏 E**：从自动发现的水平／垂直轴上找至少三个不重叠的同类型对象，按位置排序，比较连续边缘空隙。`MAD(空隙)/max(median(空隙),4)` ≤0.05 得 1，≥0.40 得 0，中间插值；MAD 为绝对偏差的中位数。所有空隙为零时不评价节奏。每个对象在同一方向只加入覆盖最多的一条序列，避免重复计数。

`R=100×(0.70T+0.30E)`。无节奏依据时仅用 T，标记证据有限。少量独特元素可能承担强调作用，提示应写“未找到相似样式”，不能声称它必须与其他元素统一。很多相同图形只增加证据，分数不按数量累加。

## 5. 对比：可见度与视觉差异

至少一个可见文字或图形即可计算可见度 V；两个以上前景对象才计算视觉差异 D。初始权重为 V 70%、D 30%；只有 V 时按 V 计算并标记 `limited`。

### 5.1 可见度 V

文字与实际背景的明暗对比率：

```text
CR = (较亮相对亮度 + 0.05) / (较暗相对亮度 + 0.05)
子分 = clip((CR - 1) / (参考目标 - 1))
```

标准 sRGB 分量先线性化，再以 0.2126、0.7152、0.0722 加权求相对亮度。普通文字参考目标 4.5，大字参考目标 3；大字初值为字号≥24，或字号≥18.67 且字重≥700。方法与文字阈值参考 [W3C 文字对比说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，不能把参考分作为可访问性合规认证。

图形使用有效填充／描边对相邻实际背景的明暗对比，项目参考目标为 3，不称其为适用于所有装饰的强制标准。线条只检查描边；无填充图形只检查其可见轮廓。

背景按实际绘制层级及形状解析，无填充区域透出下层颜色。文字跨越多个底色时取最差有效区域，忽略抗锯齿边缘噪声；文字上方对象按遮挡处理，不能视为新背景。使用实际占据区域掩膜或字形行区域近似，不能只取中心点颜色。

文字子分乘以有效区域比例：将裁切、上层遮挡及其他文字碰撞的受损区域取并集，除以完整字形区域面积，再用1减去该比例。同一区域只扣减一次。图形子分仅乘以未裁切比例，图形间部分重叠仅报告，不自动扣分；完全不可见对象按第 2 节处理。先分别计算文字／图形类均值，再对存在的类别等权平均，避免大量装饰掩盖文字问题。

### 5.2 视觉差异 D

每个对象取其与其他对象的最大差异，再对对象取中位数。每对差异取尺度、明暗、文字字重三个可用通道的最大值：

- 尺度：文字用字号，图形用有效区域面积的平方根；只在同类别内比较，大小比从 1 到 1.8 映射为 0 到 1。
- 明暗：有效主色的相对亮度差从 0 到 0.35 映射为 0 到 1。
- 字重：仅文字之间比较，字重差从 0 到 300 映射为 0 到 1。

所有通道在两端外截断。无可用通道的对象不参与 D；图形多色时以有效填充为主色，无填充时用描边色。

`C=100×(0.70V+0.30D)`。D 只说明差异存在，不预测视线落点或判断强调是否正确。相同黑字可有高可见度、低差异分；纯图形也能得到对比分，不因没有文字判零。低对比分也不能直接推导为配色不美观。

## 6. 对齐：是否存在稳定的视觉联系

至少两个前景对象即可评价。分别比较左／中／右的 X 锚点、上／中／下的 Y 锚点，文字另有基线；只比较同种锚点。线条使用端点及中点的水平／垂直位置，不能把斜线的包围盒当作完整矩形参与全部边缘关系。

无需用户选择模式：多条轴可同时存在，居中、双列和网格都可获得支持。对非重叠对象的同类锚点进行一维聚类，每簇跨度不超过 20 逻辑单位，候选轴至少含两个对象；另一方向须有分离，重叠堆放不产生轴线奖励。

每个对象的支持度为其到其他对象的同类锚点最小偏差对应分：≤2 得 1，≥20 得 0，中间线性插值。只在上述有效关系中取值；没有支持则为 0。`A=100×所有前景对象支持度均值`。对象足够但没有轴线时为 0，不改成 N/A。

首版只检查水平、垂直及文字基线，不判断弧线或自由散点构图。反馈写“未发现稳定轴线”，不写“必须左对齐”。

## 7. 综合分、覆盖与异常

```text
有效维度 = score 非 null 且状态为 valid 或 limited 的维度
参考综合分 = round(有效维度未舍入分之和 / 有效维度数)
```

四项均有效时显示“四维综合参考分：83/100”；三项有效时显示“部分维度参考分：84/100（3/4 项可评）”。N/A 不按 0 或 100 补齐。四项都有分但子项覆盖不足时，也须显示“证据有限”。没有有效维度时总分为 null。

对象覆盖度与维度覆盖度分别呈现，不能混为一个百分比。不同覆盖范围不得直接排名；版本比较并列显示有效维度、参与对象、有效子项及规则版本。合法删除不设固定扣分或分数上限，只更新当前画面与覆盖变化。

重复 ID、非有限坐标、非法尺寸、未知类型、不可解析颜色等阻止评分。字体未就绪显示“计算中”，失败显示原因；不把历史分冒充当前分。暂时不能评分仍允许保存；损坏导入不能覆盖已有场景。

## 8. 接口与反馈

```ts
type DimensionKey = 'proximity' | 'repetition' | 'contrast' | 'alignment';
type RuleEvidence = {
  ruleId: string;
  elementIds: string[];
  severity: 'info' | 'suggestion' | 'warning';
  measurements: Record<string, number | string>;
  explanation: string;
  suggestion?: string;
};
type DimensionScore = {
  score: number | null;
  status: 'valid' | 'limited' | 'not-applicable';
  evaluatedIds: string[];
  evaluatedVisualUnitCount: number;
  visibleForegroundCount: number;
  applicableSubmetrics: string[];
  unavailableReasons: string[];
  evidence: RuleEvidence[];
};
type ScoreReport = {
  rubricVersion: '2.0';
  sceneRevision: number;
  sceneFingerprint: string;
  layoutVersion: string;
  fontManifestVersion: string;
  dimensions: Record<DimensionKey, DimensionScore>;
  total: number | null;
  totalKind: 'four-dimension-reference' | 'partial-reference' | 'unavailable';
  applicableDimensionCount: number;
  warnings: RuleEvidence[];
};
// 纯函数；字体等待、时间戳、持久化由调用层处理。
evaluate(scene, measuredLayout, ruleConfig): ScoreReport
```

先显示裁切、文字遮挡与难辨问题，再列最多三条结构建议，同时保留正向证据。示例：“这三个矩形已形成近似等距重复”；“右侧两个文本块的左边缘相差 13，可尝试建立共同轴线”；“只识别到一个组，暂不评价组间亲密性”。

流程依次为校验、等待字体、测量渲染、解析可见区域与背景、生成关系、计算分项与综合分。提交时核对 `sceneRevision`，丢弃过期结果。同场景及同版本组合得到同一报告；推断集合、测量依据随快照保存。

## 9. 示例与验收

| 场景／操作 | 预期结果 |
| --- | --- |
| 空画布／只有背景色 | 四项 N/A，总分 null，提示添加内容 |
| 只有一段自定义文字 | 仅对比可见度可评，显示 1/4 |
| 两个圆形 | 对比、对齐可评，另外两项 N/A |
| 六个纯图形形成两个稳定小组 | 可获得四维参考分，无需文字、角色或手动分组 |
| 均匀单列／规则网格 | 亲密性可为 N/A，重复、对齐仍可较高 |
| P=80、R=84、C=76、A=92 | 四维综合参考分 83/100 |
| P=N/A、R=84、C=76、A=92 | 部分维度参考分 84/100，显示 3/4 |
| 删除、清空或改写任意文字 | 正常重评，无原文校验或必需对象惩罚 |
| 删除后只剩一个对象 | 更新为部分维度报告，不保留旧四维分 |
| 修改文字、尺寸、颜色、背景或线条端点 | 重测相关关系，反馈对应当前对象 |
| 重复复制完全重合的同外观对象 | 折叠结构证据，不因副本数量增加得分 |
| 全部文字堆到同一点 | 无有效轴线支持；遮挡碰撞影响可见度 |
| 底板放文字后／放文字前 | 分别计算实际背景／遮挡，层级不混淆 |
| 无填充框、斜线、星形覆盖文字 | 按真实区域处理，不按完整包围盒误判 |
| 50%、100%、150% 预览缩放 | 四维与综合分一致 |
| 全体平移且未触碰画布边界 | 结构分不变 |
| 导出导入、撤销重做 | 同场景及版本恢复同一报告 |
| 字体延迟、损坏 JSON、计算时继续拖动 | 等待、拒绝损坏输入、丢弃过期结果 |

测试覆盖 N/A 分母、去重、边界、字体和层级颜色；另用单组、多组、网格、纯图形及有意不规则构图检查误判。验收目标是结果可复算、反馈与测量一致、局限如实呈现，不是让所有示例接近 100 分。
